Rift app design · v1

Principles

This is the design the Qt Quick app is built from. Every color, size and motion value here maps to design/tokens.json and design/Theme.qml. Use the bar above to switch Stone (light) / Obsidian (dark), density and accent: every screen follows.

Calm list, loud signal.

Neutral warm surfaces; color only means something: state, direction (↓ green, ↑ orange), type (torrent cobalt, HTTP orange), or the accent for focus and selection.

Real numbers only.

Speeds are measured payload, mono and tabular so they don't jitter. Rows add up to the status-bar total. Limits are shown next to capped speeds (PLAN 4.17).

Keyboard first, mouse friendly.

Every action has a menu item, a shortcut and a palette entry. 24 px minimum hit targets, visible focus rings, screen-reader names on every control.

Native, not web.

Native window frame and menus on macOS; native file dialogs; system notifications; tray / menu-bar icon. Inside the window, Rift's own components.

One rift signature.

Dialogs, cards and empty states use the asymmetric "rift" corner (14 / 4 / 14 / 4). Lists, inputs and menus stay square-ish and dense.

Fast feels fast.

Optimistic UI (pause shows instantly), 120–280 ms transitions, no animation on data refresh, and reduced motion honored everywhere.

Tokens

Color

Surfaces step from window (chrome) → sidebar → surface (lists) → raised (dialogs, menus, cards). Text has three levels. Semantic colors always come with a soft tint for backgrounds.

State colors (torrents and downloads)

Accent choices (Settings → Appearance)

Cobalt (default)SignalGreen VioletTealRose
Direction: download is always green ↓, upload always orange ↑, in lists, graphs and the tray.
Type: TORRENT uses the torrent hue, HTTP the signal hue. Never rely on color alone: the label is always present.
Contrast: text and text2 meet 4.5:1 on every surface in both themes; text3 is for non-essential metadata only (≥ 3:1).
Tokens

Typography

Bricolage Grotesque (variable: weight, width, optical size) for UI and display, JetBrains Mono for numbers, hashes, paths and captions, Instrument Serif italic only for one-word accents in the wizard and empty states. All three are bundled in the app (OFL).

Tokens

Space, radius, elevation, motion

4 px grid. Compact density is the default (30 px rows and controls); Comfortable uses 40 px rows and 34 px controls.

Assets

Icons

One custom set on a 24 × 24 grid, 1.75 px stroke, round caps. Rendered at 16 px (default), 14 px (dense), 20 px (toolbar on comfortable) and 32 px (empty states). Ship as SVG in ui/assets/icons/.

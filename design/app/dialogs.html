Dialogs · rules

How every dialog behaves

Dialogs are in-window sheets over a scrim (not OS windows), except Settings and Create torrent, which are real windows. Three widths: 420 (confirm), 560 (form), 760 (rich).

Open: scrim fades 180 ms; dialog scales 0.97 → 1 and fades with the spring curve (280 ms). Close: 120 ms exit curve. Reduced motion: fade only.
Keys: Enter = primary button, Esc = cancel, Tab cycles inside (focus trapped). First field focused on open.
Buttons: primary on the right, cancel left of it, extra options far left. Destructive primary uses the danger style and never gets default focus.
Memory: every "Don't ask again" is listed in Settings → General → Confirmations so it can be undone.
Validation: inline under the field, red text and border, shown after blur or submit, never while typing the first characters.
Corner: dialogs use the Rift corner (14 / 4 / 14 / 4). Menus and popovers use 8.

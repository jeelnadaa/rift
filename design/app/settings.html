Settings

A separate 960 × 680 window. Changes apply instantly (no OK button) except the few that need a restart, which collect in a bar at the bottom. Search filters every option across all pages. A blue dot marks values changed from the default; right-click → "Reset to default".

Rift Settings
1 change needs a restart: Listening port
Search: typing filters to matching rows across all pages; pages without matches hide; match text highlighted.
Locked: options set by portable mode or command line show a lock and a tooltip with the source.
Import / export: Advanced → "Export settings…" writes a JSON file; never includes passwords.

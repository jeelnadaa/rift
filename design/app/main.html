Screen 1 · PLAN §5.1

Main window

Interactive. Click rows (Ctrl/Shift for multi-select), right-click for the context menu, switch sidebar filters, sort columns, type in the filter box, and open every details tab. Use the switches to see the window states.

Window state
Rift↓ 18.4 MB/s · ↑ 2.1 MB/s
Layout: sidebar 232 px (184–360, collapsible with Ctrl B). Details panel default 300 px, drag to resize, double-click divider to collapse, or dock right (View → Details on the right).
Refresh: rows update in place every 500 ms (1 s when minimized). No row animation on data refresh; only progress width eases (280 ms).
Selection: click, Ctrl/Cmd-click, Shift-range, Ctrl A. Multi-select swaps the toolbar for the blue bulk bar. Esc clears.
Keyboard: ↑↓ move, Space pause/resume, Del remove, Enter open folder, Ctrl C copy magnet, F2 rename, Ctrl 1–8 details tabs.
Drag & drop: dropping files/links anywhere shows a full-window drop overlay ("Drop to add"). Rows can be dragged to reorder the queue or onto a category/tag in the sidebar.
Window title & taskbar: title shows total speeds; taskbar/dock shows overall progress; tray tooltip shows ↓/↑ and active count.

Screen 1 · status bar

Status bar states

Left: speeds (with limit when capped). Middle: connection health. Right: disk, VPN, alt-speed toggle. Every item has a tooltip explaining itself; clicking opens the related settings page.

Offline · no network
